# আপা আসবে?

> কিছু নিউজ বলছে আপা মারা গেছেন, কিছু নিউজ বলছে বেঁচে আছেন, আর কেউ বলছে ডিসেম্বরে আসবেন।
> এই জাতীয় কনফিউশন নিয়ে একটা নির্ভেজাল **স্যাটায়ার** ওয়েবসাইট।

## ফিচার

- **শ্রোডিঙ্গারের আপা** — বাক্স খুলুন, জানুন আজ তিনি জীবিত, মৃত, নাকি দিল্লিতে ব্যস্ত।
- **গুজব-ও-মিটার** — "মারা গেছেন" থেকে "বেঁচে আছেন" পর্যন্ত দোলায়মান কাঁটা।
- **আপা আসার কাউন্টডাউন** — ডিসেম্বর পর্যন্ত গোনে, তারপর নিজে নিজেই পরের বছরে পিছিয়ে যায়।
- **আওয়ামী লীগ ওয়েটিং রুম** — প্রগ্রেস বার যা ৯৯%-এ গিয়ে আটকে যায়।
- **গুজব জেনারেটর** — ইউটিউব চ্যানেলের জন্য ফ্রেশ, ভিত্তিহীন গুজব।
- **গুজব যাচাই কেন্দ্র** — অত্যাধুনিক "আন্দাজ ইঞ্জিন"।
- **জনমত জরিপ** — ফলাফল আগে থেকেই ঠিক করা, ঐতিহ্য মেনে।

## চালানো

কোনো বিল্ড স্টেপ নেই, শুধু স্ট্যাটিক HTML/CSS/JS।

```bash
npx serve .
```

## Vercel-এ ডিপ্লয়

1. এই রিপো GitHub-এ পুশ করুন।
2. [vercel.com/new](https://vercel.com/new) থেকে রিপোটি ইমপোর্ট করুন।
3. Framework Preset: **Other**, Build Command: খালি, Output Directory: `.` — তারপর Deploy।

## ডিসক্লেমার

এটি সম্পূর্ণ ব্যঙ্গাত্মক (satire) প্রজেক্ট। সব "খবর", "সূত্র", "উক্তির পরবর্তী ঘটনা" ও "জরিপ" কাল্পনিক এবং কোনো প্রকৃত সংবাদমাধ্যমের সাথে সম্পর্কিত নয়।
